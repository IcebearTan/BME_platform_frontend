# 更新日志

此文件记录了教育平台前端项目的所有重要更改。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
此项目遵循 [语义化版本控制](https://semver.org/lang/zh-CN/)。

## [2.1.2] - 2025-09-01

### 🚀 更改

- 项目仓库迁移：项目已迁移至新的代码仓库，提升开发效率
- 依赖项更新：升级了项目依赖包，提升性能和安全性
- 配置优化：优化了构建配置，改善开发体验

### 🐛 修复

- 修复了已知问题，提升系统稳定性
- 统一了 package.json 和配置文件中的版本号

### 📝 重要提醒

- 此次更新主要为项目迁移和维护性更新，如遇到问题请及时反馈！

## [2.1.0] - 2025-07-14

### 📚 新增

- 全新任务管理系统：老师可以发布任务，设置截止时间和优先级
- 在线作业提交功能：支持文字内容和文件上传，方便快捷
- 智能批改系统：老师可以在线批改作业，给出分数和评语
- 提交状态跟踪：实时查看作业提交情况，已提交/未提交一目了然
- 截止时间提醒：系统会显示作业截止状态，避免逾期提交
- 作业修改功能：截止时间前可以重新提交修改作业内容

### 📝 使用说明

- 请同学们及时关注任务列表，按时完成并提交作业
- 逾期将无法提交，请合理安排时间！

## [2.0.0] - 2025-04-10

### 🌟 新增

- 线上打卡的最大签退时间延长至 6小时，要记得好好签退哦！
- 新增了网站的更新公告，会在每次网站更新后的第一次登录时显示

### 🔧 更改

- 修改了签到系统的部分逻辑，现在重新登录会同步签到中的时间

## 版本号规则

我们遵循 [语义化版本控制](https://semver.org/lang/zh-CN/) 规范：

- **主版本号（MAJOR）**：当进行不兼容的 API 更改时
- **次版本号（MINOR）**：当添加向后兼容的功能时
- **修订号（PATCH）**：当进行向后兼容的问题修复时
