## 阶段一：安全与上线前修复（P0）

> 这些问题影响安全性或功能正确性，必须最先解决。

### 1.1 API 地址改为环境变量

**文件：** `src/api.js`

- 在项目根目录新建 `.env`（开发）和 `.env.production`（生产）
- 将 `http://172.25.56.83:8080/api` 替换为 `import.meta.env.VITE_API_BASE_URL`
- 删除文件中所有注释掉的历史 IP 地址
- 将 `.env` 加入 `.gitignore`

```
# .env
VITE_API_BASE_URL=http://172.25.56.83:8080/api

# .env.production
VITE_API_BASE_URL=https://your-production-domain/api
```

---

### 1.2 Mock 系统改为环境变量控制

**文件：** `src/mock/config.js`

- 将 `enabled: true` 改为读取 `import.meta.env.VITE_USE_MOCK`
- 移除"API 失败自动回退 mock"的逻辑
- 在开发模式且 Mock 开启时，在页面顶部显示醒目的 Mock 标识横幅

```
# .env（本地开发）
VITE_USE_MOCK=true
```

---

### 1.3 补完路由守卫

**文件：** `src/router.js`

- 给所有需要登录的路由添加 `meta: { requiresAuth: true }` 标记
- 在 `router.beforeEach` 中统一处理未登录重定向到 `/login`
- 删除各组件 `onMounted` 中分散的 `checkLogin()` 调用

```js
// 目标守卫结构
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  if (to.meta.requiresAuth && !token) {
    next('/login')
  } else if (to.path === '/' && token) {
    next('/home')
  } else {
    next()
  }
})
```

## 阶段二：结构性重构（P1）

> 收益最高的改动，消除大量重复代码，改善性能。

### 2.1 建立 CSS 变量体系

**新建目录：** `src/styles/`

**步骤：**

1. 新建 `src/styles/tokens.css`，将全项目所有颜色、间距、过渡时间定义为 CSS 变量
2. 新建 `src/styles/theme.css`，只在这里定义 `.theme-dark` 对变量的覆盖值
3. 新建 `src/styles/global.css`，放全局 reset、滚动条美化、基础排版
4. 新建 `src/styles/element-overrides.css`，将 `MenuComponent.vue` 中 30+ 处 `!important` 统一迁移到此处
5. 在 `main.js` 中按顺序引入这 4 个文件
6. 逐步将各组件中的 `.theme-light` / `.theme-dark` 硬编码颜色替换为 CSS 变量

**目标效果：** 消除分散在 27 个文件中的 335 处主题样式重复

```css
/* src/styles/tokens.css */
:root {
  --bg-primary: #ffffff;
  --bg-secondary: #f5f7fa;
  --text-primary: #303133;
  --text-secondary: #6b7280;
  --border-color: rgba(0, 0, 0, 0.06);
  --transition-base: all 0.3s ease;
}

.theme-dark {
  --bg-primary: #1a1a1a;
  --bg-secondary: #1e1e1e;
  --text-primary: #ecf0f1;
  --text-secondary: #a1a1aa;
  --border-color: rgba(255, 255, 255, 0.1);
}
```

---

### 2.2 抽取 `<PageLayout>` 布局组件

**新建文件：** `src/components/layout/PageLayout.vue`

**步骤：**

1. 将以下 10 个 View 中重复的模板、JS、CSS 提取到 `PageLayout.vue`：
   - `HomeView`、`StudyView`、`GroupView`、`ArticleView`、`CommunityView`
   - `ProfileView`、`ServiceHallView`、`ThreeDPrintView`、`UserCenter`、`QuestionBankView`
2. `PageLayout.vue` 内部处理 `isMobile`、`isMobileMenuOpen`、resize 监听、MenuComponent、MobileMenuComponent、PageFooterComponent
3. 每个 View 只保留自身内容，通过默认 `<slot>` 插入

**目标效果：** 每个 View 减少约 50 行模板 + 20 行 JS + 30 行 CSS

```vue
<!-- 改造后的 HomeView.vue（示意） -->
<template>
  <PageLayout>
    <!-- 页面自身内容 -->
  </PageLayout>
</template>
```

---

### 2.3 抽取 `<AuthLayout>` 认证页布局

**新建文件：** `src/components/layout/AuthLayout.vue`

**步骤：**

1. 将 `LoginView`、`RegisterView`、`FindPasswordView` 三个文件中完全相同的背景装饰（`.bg-decorations`、`.bg-circle`、`@keyframes float/pulse` 等约 200 行 CSS）提取到 `AuthLayout.vue`
2. 三个 View 通过 slot 插入表单内容

**目标效果：** 消除约 600 行冗余 CSS

---

### 2.4 路由全部改为懒加载

**文件：** `src/router.js`

将 19 个同步 `import` 全部改为动态导入：

```js
// 改前
import HomeView from './views/HomeView.vue'

// 改后
const HomeView = () => import('./views/HomeView.vue')
```

**目标效果：** 首屏 bundle 体积显著减小，只加载当前路由所需代码

---

### 2.5 Element Plus 图标改为按需引入

**文件：** `src/main.js`

- 删除全量注册循环
- 改用 `unplugin-icons` 插件，或手动只注册项目实际使用的图标
- 安装：`npm install unplugin-icons -D`

```js
// 改前（main.js）
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

// 改后：只注册用到的图标
import { Search, User, Menu, ... } from '@element-plus/icons-vue'
app.component('Search', Search)
// ...
```

---

### 2.6 统一滚动条样式到全局

**文件：** `src/styles/global.css`（新建）

将 7 个组件中各自实现的滚动条样式提取到 `global.css` 中统一定义一次，各组件删除各自的滚动条 CSS。

## 阶段三：架构优化（P2）

### 3.1 Vuex Store 模块化

**目标结构：**
```
src/store/
├── index.js
└── modules/
    ├── auth.js      ← token、isLogin
    ├── user.js      ← user、avatar
    ├── checkin.js   ← checkinInfo
    └── theme.js     ← isDarkMode
```

**步骤：**

1. 新建 `src/store/` 目录
2. 按模块拆分当前 `src/store.js` 内容
3. `src/store/index.js` 通过 `modules` 选项组合
4. 更新所有 `mapState`、`mapMutations`、`mapActions` 的命名空间引用
5. 删除旧的 `src/store.js`

---

### 3.2 统一 Token 来源

**文件：** `src/api.js`、`src/store/modules/auth.js`

- 选择单一来源：推荐只用 Vuex + vuex-persistedstate 持久化
- `api.js` 的请求拦截器改为从 Vuex store 读取 token，不再直接访问 localStorage
- 确保 `clearToken` mutation 同步清除 localStorage

---

### 3.3 拆分 GroupView.vue（1541 行）

**目标结构：**
```
src/views/
├── GroupListView.vue    ← 小组列表、搜索、创建入口
└── GroupDetailView.vue  ← 小组详情、子 tab 路由
```

同步更新 `src/router.js` 中的路由配置。

---

### 3.4 统一为 Composition API

**涉及文件：** `MenuComponent.vue`、`App.vue`、`LoginView.vue` 等使用 Options API 的文件

- 优先处理 `MenuComponent.vue`（同时含 `<script>` 和 `<script setup>` 两个块，属于反模式）
- 其余文件可在后续迭代中逐步迁移

---

### 3.5 全局统一使用 `@/` 路径别名

**文件：** 全项目所有 `.vue` 文件的 import 语句

将所有相对路径（`../../api`、`../components/...`）替换为 `@/` 前缀。可通过 IDE 的全局查找替换批量处理。

---

### 3.6 勋章图片压缩

**目录：** `public/medals/`

- 将 22 张 PNG（每张 1-3.6MB，总计 50MB+）全部转为 WebP 格式
- 目标：每张控制在 50-100KB 以内
- 工具推荐：`cwebp`、Squoosh、或 `vite-plugin-imagemin`
