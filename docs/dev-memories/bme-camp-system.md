BME 平台正在开发**营期(Camp)考勤系统**（甲方需求，2026-07 启动）。

**规划与进度文档**：`BME_platform_flask/docs/营期考勤系统-规划.md`（需求拆解/现状/数据模型/API/看板算法/分阶段计划 + 实时进度）。详细执行计划：`~/.claude/plans/1-2-3-rbac-radiant-pinwheel.md`。

**核心**：按营期(如 2026暑期营)独立管理 导生/学员/座位/课程；记录每人**承诺出勤日期**(范围内工作日)；实际考勤 vs 承诺形成**看板**(仅老师+导生，老师=全营 / 导生=本团队)；**弹性考勤** = 迟到维度 + 当日时长达标维度 双判。

**关键决策**(已与甲方确认)：4 级角色见 [[bme-rbac-roles]]；营期成员用**独立 `CampMember` 表**(不碰共享 CourseGroup，隔离安全)；现有 admin→super_admin；导生团队 = `CampMember.team_mentor_id`；UI DewUI 优先、Element Plus 兜底；复用 notification 系统(`category='camp'`)。
