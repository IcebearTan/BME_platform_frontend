不要把**蓝紫渐变**（blue → purple，如 `#60a5fa → #a78bfa`）当作默认首选的装饰手段——强调条、背景、渐变文字都别一上来就用它。

**Why:** 出勤月榜标题左侧我加了蓝紫渐变强调条，用户嫌"好丑"，并明确要求"无论什么时候都禁止首先使用蓝紫渐变"。蓝紫渐变是烂大街的 AI/通用 SaaS 配色，跟 Dew 液态玻璃（偏中性、柔和、靠材质而非花色）的设计语言不搭。

**How to apply:** 需要强调/装饰时，优先中性色、单色、或 Dew 玻璃材质本身（玻璃高光、柔和阴影）。要用彩色就选明确语义色（金/银/铜奖牌、success/warning 等），不要无脑蓝→紫。只有用户明确点名要蓝紫渐变时才用。参见 [[dew-ui-progress]] [[feedback-no-emoji-icons]]。
