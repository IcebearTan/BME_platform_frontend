# UI 微调偏好

**Why:** 在调整 DewSwitch 尺寸时，AI 每次只调 2px，来回多轮才到位，用户觉得太小心翼翼。

**How to apply:** 当用户说"再大一点/再长一点/再宽一点"这类 UI 微调时，大胆调整（一步到位 ±4~8px 或直接给到目标比例），不要每次只挪 2px。如果不确定目标值，宁可调过头再回调，也不要一点点试探。
