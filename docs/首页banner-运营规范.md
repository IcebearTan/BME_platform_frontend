# 首页 Banner 使用与更换规范

> 版本：2.0（2026-09-15 轮播 DB 化改版；1.0 见文末沿革）
> 适用：用户端首页 `StudyHub.vue` 轮播 banner 的**全部帧**（2026-09-15 起由 banner 表 DB 驱动）。

## 1. 现行机制（2026-09-15 起）

轮播帧存 DB `banner` 表，图走对象存储（`media/banners/`，经 `/media/` 公开路由出图，immutable 强缓存）。管理端**「内容与课程 → 首页轮播」**页（`/banner/manage`）维护：新建 / 编辑 / 换图 / 排序（上移下移）/ 显隐 / 删除。

**换图、调顺序、上下线全程零代码零发版**——管理页改完即生效（图 URL 带 uuid，浏览器缓存自动失效刷新）。

### 帧字段语义

| 字段 | 说明 |
|---|---|
| 标题 / 描述 | 角标文案（营期帧模式下标题会被主推营名覆盖） |
| 跳转类型 | `route`（站内路由如 `/camp`）/ `external`（新窗口开外链如 `/3dfarm/`）/ `none` |
| 营期帧（`is_camp_frame`） | 能力位：开启后此帧叠加 `/camp/featured` 主推营动态角标（有营显示营名+招募中绿点，无营显示「新营期筹备中」），点击去 `/camp-home`。**09-14 起默认不用**（用户定：撤动态帧，营期动态在营期中心看），保留标志位是给未来想恢复时零代码开启 |
| 可见 | 首页是否展示（新建帧默认隐藏，传完图再开） |
| 显示焦点 `image_focus_y` | 0-100（默认 50）：展示条纵向取景位置——0 偏上、50 中带、100 偏下 |

### 底图资产规范（上传约束）

- 尺寸 **1600×800**（2:1，展示区高 160px 全宽）；系统自动转码 WebP 并压到 **≤500KB**，上传源给 jpg/png/webp ≤10MB 即可；
- **底图不得含烧录文字**：文案一律由渲染层出（左下角状态条 / 角标）。历史底图「秋季学期营」含烧录大标题属违规存量，已原样压缩入库，下次视觉更新时请在管理页直接换无字底图；
- 状态条落位左下角：新底图请保持**左下角 30% 区域低密度**。

## 2. 常见操作

- **换底图**：管理页该帧「换图」→ 选图后先进**裁切器**（2:1 取景所见即所得，拖拽平移/滚轮缩放）→「确认裁切并上传」热替换（旧图对象自动清理）。新建帧选底图同样走裁切器；
- **调裁切/构图**：底图主体不在中部导致展示「歪」时两条路——①「换图」重新取景；②帧「编辑」里的**显示焦点**滑杆（0-100）：控制首页展示条（全宽 ×160px，比 2:1 更扁）在底图上的纵向取景位置，50=中带默认，带即时预览，改完保存即生效，无需重新传图；
- **加一帧**：新建（必选底图）→ 默认隐藏 → 列表里开「可见」；
- **调顺序**：上移/下移（首页按顺序轮播）；
- **下线一帧**：关「可见」开关（不删数据，随时恢复）。

## 3. 相邻入口（不在本规范范围，防混淆）

- 顶栏导航「学期营」logo（`MenuComponent` campLogo）：品牌位，**不随营期切换**；
- 营期中心 `/camp`：一切营期事务的家（IA 规范）。

## 4. 实现位置与测试

- 后端：`blueprints/banner.py`（公开 `GET /banner/list` + admin CRUD），`BannerModel`；
- 前端：`StudyHub.vue` 的 `fetchBanners()` / `applyFeaturedBanner()`；admin `BannerManage.vue`；
- e2e：`user.spec.js` 首页 banner 用例（mock `/banner/list`）。
