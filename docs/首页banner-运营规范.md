# 首页 Banner（学期营帧）使用与更换规范

> 版本：1.0（2026-09-11 状态化改造时制定）
> 适用：用户端首页 `StudyHub.vue` 轮播 banner 的**第 1 帧（学期营帧）**。
> 第 2/3 帧（大模型服务中心 / 3D 打印农场）仍是静态帧，改动需发版，不适用本文。

## 1. 状态化行为（2026-09-11 起）

第 1 帧由 `/camp/featured` 主推营期驱动，**换营期零代码零发版**：

| 场景 | banner 显示 | 点击去向 |
|---|---|---|
| 有主推营（upcoming/selecting） | 玻璃状态条：`{营期名} · 报名进行中，点击进入`（selecting，绿点）/ `· 即将开放，点击了解`（upcoming） | 该营工作台 `/camp?sid=<id>`（成员即工作台；非成员即见 CampJoin 报名页——报名全站唯一入口在工作台内） |
| 无主推营 | `新营期筹备中 · 敬请期待`（灰、无点） | `/camp` 营期中心 |
| featured 接口失败 | 静默退回默认帧（无状态条） | `/camp` |

实现位置：`StudyHub.vue` 的 `applyFeaturedBanner()`；e2e：`user.spec.js`「首页学期营 banner」两条用例。

## 2. 换营期怎么做（使用方法）

1. 管理端「营期管理」把新一期营（须为**待开放/选择阶段**）**设为招募营期**——`PUT /camp/sessions/<sid>/feature`（互斥：同时只有一期主推）；
2. 完成。首页 banner 标题/状态/链接自动切换，营期归档后自动回兜底帧，全程不需要改代码、不需要发版、不需要换图。

## 3. 底图资产规范（更换规范）

- **底图不得含烧录文字**：营期名/状态一律由状态条渲染层出。当前底图 `apps/user/public/2026秋季学期营.png` 含烧录的「秋季学期营」大标题，属**违规存量**（状态化前所制），下次视觉更新时必须替换为无字底图；
- 替换方法：新图覆盖同路径同名文件，或改 `StudyHub.vue` 的 `CAMP_BANNER_IMAGE` 常量指向新文件；
- 尺寸建议 **1600×800**（2:1，展示区高 160px 全宽）；体积 **≤500KB**（现存量 1.94MB 超标，替换时顺带压缩；SVG 更佳）；
- 状态条落位左下角（底图左上/右上已有元素区已避开）；新底图请保持左下角 30% 区域低密度。

## 4. 相邻入口（不在本规范范围，防混淆）

- 顶栏导航「学期营」logo（`MenuComponent` campLogo）：品牌位，**不随营期切换**，点击直达主推营（已 featured 驱动）；
- 营期中心 `/camp`：一切营期事务的家（IA 规范）。

## 5. 默认兜底文案调整

「新营期筹备中 · 敬请期待」为 2026-09-11 上线时的默认选择（保持布局不塌）；要改为品牌静态图/隐藏该帧，改 `applyFeaturedBanner()` 的无 session 分支即可。
