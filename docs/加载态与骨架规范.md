# 加载态与骨架规范（全站）

> v1.0 · 2026-09-15 · 基于 DewUI（DewSkeleton + DewImage）
> 背景：静态资源重构后走 `/media/` 按需直读（内容不可变 + immutable 强缓存 + ETag 304），延迟痛点集中在**首次加载**；二次访问全走浏览器缓存零延迟。加载体系的目标 = 诚实掩盖首载，缓存命中零打扰。

---

## §1 四层体系

| 层 | 场景 | 工具 | 规则 |
|---|---|---|---|
| L0 应用首屏 | JS 包加载白屏 | index.html 内联 splash | 只兜「包未执行」的窗口期（当前全站无路由懒加载，首包大，L0 必要） |
| L1 数据骨架 | 接口数据未到 | **DewSkeleton** | 三段式：`loading`（初始 true）→ 内容 → error/空态；骨架**形制对齐真实内容**（同布局同尺寸），防 CLS |
| L2 图片三态 | 图片字节未到 | **DewImage** | 骨架呼吸 → 淡入 → 错误兜底（circle 显首字 / rect 显占位图标）；比例盒先占位 |
| L3 微加载 | 按钮提交/局部刷新 | 按钮 loading 态 / 行内 spinner | 不整页遮罩 |

## §2 硬规则

1. **图片一律 DewImage，禁止裸 `<img :src>` / 裸 `el-avatar` 接远程地址**。DewImage 自带：懒加载（首屏关键图 `:lazy="false"`）、异步解码、`@error` 兜底、换 src 重走三态、`position` 取景（banner focusY）。
2. **远程相对路径一律过 `assetUrl()`**（`services/campService` re-export）。dev 跨域下不过它 = 404。已知教训：出勤榜头像、组织架构页、文章 v1/v2 作者头像曾漏。
3. **骨架不许撒谎**：形状、尺寸、数量对齐即将出现的内容；加载态和真实态的容器高度差 = CLS。
4. **互不依赖的请求并行发**（`Promise.allSettled`），别串行 await 把骨架期拉长（LivePanel 曾三连串行慢三倍）。
5. **失败必须可见**：接口挂了给 error 文案 + 重试入口；图片挂了 DewImage 兜底态，不许空白。
6. 骨架裸浮在页面底色上时（无卡片容器），局部加深 `--dew-skeleton-bg`（默认 6% 黑在极光底上不可见，参考 LivePanel 的主题感知覆盖写法）。
7. `prefers-reduced-motion` 下所有加载动画应静止（DewImage/DewSkeleton 已内置，自定义动画自己加）。

## §3 新页面 Checklist（设计期就要过）

- [ ] 这个页面等数据时长什么样？（L1 骨架，画出三段式）
- [ ] 页面里每张远程图，加载中/失败各长什么样？（L2 DewImage）
- [ ] 有没有可以先占位的固定版位（比例盒 / 定高行），数据到了不推布局？
- [ ] 多个请求有没有串行依赖？没有就并行。
- [ ] 新 Dew 组件先上 UiShowcase 验证再接业务页。
